# Project Context

## Project Overview
موقع إلكتروني احترافي شامل باسم Flavor Experts Network - صفحة هبوط لمجموعة خبراء النكهات على لينكد إن (8000+ عضو). يتضمن: Hero section، تعريف بالمجموعة والمؤسس Ayoub Akbik، أخبار الصناعة، موارد تعليمية، نموذج تواصل، وتذييل. التصميم احترافي متجاوب يعكس الطابع العلمي والصناعي.

| 2026-05-14 | Frontend only - صفحة واحدة بدون backend | Mike | صفحة هبوط تعريفية لا تحتاج قاعدة بيانات |

## Constraints
- الموقع صفحة هبوط واحدة (frontend فقط)
- التصميم يجب أن يعكس الطابع المهني والعلمي لمجال تكنولوجيا الغذاء والنكهات
- الموقع يجب أن يكون متجاوب مع جميع الأجهزة
- المحتوى باللغة الإنجليزية بما يتوافق مع طبيعة المجموعة الدولية على لينكد إن
