# Project Summary
The Flavor Experts Network is a cutting-edge web application aimed at a LinkedIn community comprising over 8,000 professionals in food technology and flavor science. This platform enhances networking, knowledge sharing, and collaboration, driving innovation within the flavor science sector. Founded by Talal Al Boushi and Ayoub Akbik, the platform serves as a vital resource for industry insights, educational materials, and opportunities for professional growth.

# Project Module Description
The application consists of several functional modules:
1. **Hero Section** - Displays the group name, tagline, member count, and a call-to-action (CTA) button to join the LinkedIn group.
2. **About Section** - Features the group's mission and introduces the founders, Talal Al Boushi and Ayoub Akbik, along with their vision.
3. **Industry News Section** - Showcases the latest updates in food technology and flavor science, dynamically sourced from Supabase.
4. **Educational Resources Section** - Provides articles and references for members, with premium content gated for exclusive access.
5. **Contact Form** - Allows users to send messages to group administrators, integrated with Supabase for message storage.
6. **Database Status Widget** - Displays real-time database connection status and setup instructions.
7. **Partners Section** - Highlights partner companies with logos and a CTA for potential collaboration.
8. **Footer Section** - Contains social media links, a link to the LinkedIn group, and copyright information.

# File Description Inventory
- **uploads/image-1.png**: Reference image for website design.
- **src/index.css**: Global styles including Tailwind CSS configuration.
- **src/pages/Index.tsx**: Main entry point for the landing page, integrating all sections.
- **src/pages/AuthPage.tsx**: Manages user authentication (login/signup).
- **src/pages/EmailVerificationPage.tsx**: Page for email verification after signup.
- **src/pages/EnterpriseServicesPage.tsx**: Details enterprise services offered to businesses.
- **src/pages/PricingPage.tsx**: Displays membership plans and pricing details.
- **src/components/**: Contains individual components for each section of the landing page.
- **src/lib/supabase.ts**: Configures the Supabase client for database interactions and includes database health checks.
- **src/lib/i18n.tsx**: Manages internationalization for multilingual support.
- **src/components/AboutSection.tsx**: Displays information about the founders and their vision, including image upload functionality.
- **src/components/PartnersSection.tsx**: Displays partner companies and their contributions.
- **src/components/DatabaseStatus.tsx**: Displays the connection status of the database and provides setup instructions.

# Technology Stack
- **Frontend Framework**: React
- **TypeScript**: For type safety and improved development experience
- **CSS Framework**: Tailwind CSS for styling
- **UI Components**: Shadcn-ui for building user interfaces
- **Database**: Supabase for backend data management
- **Internationalization**: i18n support for multilingual capabilities

# Usage
To set up and run the project, follow these steps:
1. Install the necessary dependencies using the package manager.
2. Execute the SQL script located at `src/lib/database-setup.sql` in the Supabase SQL Editor to create the database schema and seed data.
3. Build the application to prepare it for deployment.
4. Run the application locally to test functionalities.
